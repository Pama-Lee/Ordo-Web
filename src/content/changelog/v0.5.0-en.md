Covers engine 0.5.0 to 0.5.2 and CLI 0.5.0 to 0.6.0.

## New

- `ordo guard`: every command a coding agent wants to run goes through your local rules first, and is allowed, denied, or sent to you to decide. Works with Claude Code, Codex CLI and Cursor. The policy is an Ordo project with tests.
- `ordo replay`: replay recorded real decisions against a rule change and see which results move.
- Optional input and output capture on the server (`--capture-io-path`) to feed replay.
- Execution analytics: the engine reports execution stats, and Studio shows decision volume, outcomes and latency.
- Share a ruleset from the playground by URL.

## Fixes

- Release flow on the platform: rollback, concurrent rollouts, crash recovery and re-inlining sub-rules.
- Cross-organization data isolation gaps.
- Several Studio states that could lose unsaved work or show misleading status.
