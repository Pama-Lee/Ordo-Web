包括引擎 0.5.0 到 0.5.2，以及命令行 0.5.0 到 0.6.0。

## 新增

- `ordo guard`：编码 Agent 执行命令之前先过一遍本地规则，放行、拒绝或先问你。支持 Claude Code、Codex CLI 和 Cursor，策略本身是一个带测试的 Ordo 项目。
- `ordo replay`：用录下来的真实决策回放一次规则改动，看哪些结果会变。
- 服务端可选的输入输出录制（`--capture-io-path`），给回放提供数据。
- 执行分析：引擎上报执行统计，Studio 里可以查看决策量、结果分布和延迟。
- Playground 可以通过链接分享一个规则集。

## 修复

- 平台发布流程：回滚、并发发布、崩溃恢复和子规则重新内联的正确性问题。
- 跨组织数据隔离的漏洞。
- Studio 里几处可能丢失未保存内容或显示误导状态的问题。
