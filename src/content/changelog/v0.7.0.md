这一版的引擎改动随命令行 `@ordo-engine/cli` 0.6.1 和 0.7.0 发布。

## 引擎

- 新增 decimal 类型，金额精确计算，不再有浮点误差。数值相等、除法和 `round(x, n)` 的行为也一并修正。
- 规则集可以声明 `inputSchema`。输入字段缺失或类型不对时直接返回 400 `INVALID_INPUT`，不会悄悄走错分支。
- 赋值和输出可以直接写表达式字符串，比如 `"price * qty"`。
- 新增 `decision_table` 步骤。`hitPolicy` 支持 `first`（第一条命中）和 `collect`（收集所有命中，可以再做 sum、count、min、max）。

## 命令行

- `ordo impact <规则集>`：把工作区里的改动和 git 里的上一个版本放在一起跑，输入包括测试用例、你提供的真实输入，以及在每个阈值两侧自动生成的探测值，列出结果变了的输入。支持 `--json` 和 `--fail-on-change`。
- `ordo mcp` 新增 `impact` 工具，编码 Agent 改完规则可以自己检查影响。
- `ordo guard upgrade`：把旧版本脚手架生成的 Guard 策略升级到最新默认策略。

## 规则包

- 仓库新增 `examples/rule-packs/`：信贷审批、优惠叠加、支付风控评分。每个都是完整的 Ordo 项目，带测试，能直接用 `ordo test` 跑。
