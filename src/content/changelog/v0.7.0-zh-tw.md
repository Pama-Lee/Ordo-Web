這一版的引擎改動隨命令列 `@ordo-engine/cli` 0.6.1 和 0.7.0 釋出。

## 引擎

- 新增 decimal 型別，金額精確計算，不再有浮點誤差。數值相等、除法和 `round(x, n)` 的行為也一併修正。
- 規則集可以宣告 `inputSchema`。輸入欄位缺失或型別不對時直接返回 400 `INVALID_INPUT`，不會悄悄走錯分支。
- 賦值和輸出可以直接寫表示式字串，比如 `"price * qty"`。
- 新增 `decision_table` 步驟。`hitPolicy` 支援 `first`（第一條命中）和 `collect`（收集所有命中，可以再做 sum、count、min、max）。

## 命令列

- `ordo impact <規則集>`：把工作區裡的改動和 git 裡的上一個版本放在一起跑，輸入包括測試用例、你提供的真實輸入，以及在每個閾值兩側自動生成的探測值，列出結果變了的輸入。支援 `--json` 和 `--fail-on-change`。
- `ordo mcp` 新增 `impact` 工具，編碼 Agent 改完規則可以自己檢查影響。
- `ordo guard upgrade`：把舊版本腳手架生成的 Guard 策略升級到最新預設策略。

## 規則包

- 倉庫新增 `examples/rule-packs/`：信貸審批、優惠疊加、支付風控評分。每個都是完整的 Ordo 專案，帶測試，能直接用 `ordo test` 跑。
