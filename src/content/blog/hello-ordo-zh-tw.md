## 亮點

Ordo v0.4.0 是一個里程碑版本。我們從命令列工具和 API 起步，現在終於有了一個完整的視覺化工作台。

### Studio 編輯器

Studio 是 Ordo 的視覺化工作台。你可以在一個介面內完成以下所有事情：

- **流程圖編輯**：拖曳式建立決策流程，支援 Decision、Action、Terminal 等多種節點類型
- **決策表視圖**：用表格方式查看和編輯路由矩陣，讓業務人員也能審查規則
- **測試管理**：為每個規則集建立、執行、匯出測試套件

### 模板市集

我們內建了多個常見場景模板，並支援從 GitHub 載入社群模板。選好模板後一鍵即可建立專案。

### 平台治理

組織管理、成員權限、專案空間——Ordo 不再只是一個引擎，而是一個完整的決策平台。

## 下一步

我們正在開發 gRPC 協議支援和向量化執行引擎，敬請期待 v0.5.0。
