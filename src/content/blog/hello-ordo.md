## 亮点

Ordo v0.4.0 是一个里程碑版本。我们从命令行工具和 API 起步，现在终于有了一个完整的可视化工作台。

### Studio 编辑器

Studio 是 Ordo 的可视化工作台。你可以在一个界面内完成以下所有事情：

- **流程图编辑**：拖拽式创建决策流程，支持 Decision、Action、Terminal 等多种节点类型
- **决策表视图**：用表格方式查看和编辑路由矩阵，让业务人员也能审查规则
- **测试管理**：为每个规则集创建、运行、导出测试套件

### 模板市场

我们内置了多个常见场景模板，并支持从 GitHub 加载社区模板。选好模板后一键即可创建项目。

### 平台治理

组织管理、成员权限、项目空间——Ordo 不再只是一个引擎，而是一个完整的决策平台。

## 下一步

我们正在开发 gRPC 协议支持和向量化执行引擎，敬请期待 v0.5.0。
