## 從空白開始的成本

每次搭建新的規則集，團隊都要重複同樣的工作：定義輸入結構、想清楚分支邏輯、撰寫第一條測試案例——這些工作在不同場景下高度相似，卻每次都要重做。

模板市場解決的正是這個問題：**把業界常見的規則結構預先包裝好，讓你不必從空白檔案開始**。

---

## 內建模板涵蓋哪些場景？

**金融風控**
- 信貸審批：根據信用分、負債率、收入水準三維條件判斷是否放款
- 反欺詐：基於裝置指紋、IP 歸屬、行為序列的風險評分

**電商營運**
- 促銷策略：滿減、折扣率、定向優惠疊加規則
- 庫存路由：按庫存水位、倉庫位置、配送時效的發貨策略

**API 閘道**
- 流量路由：按請求標頭、用戶標籤、灰度比例分流
- 限流策略：按租戶等級的差異化 QPS 限制

每個模板都包含完整的測試案例，你可以在建立專案前先執行一遍，確認行為符合預期。

## GitHub 模板市場

除了內建模板，Studio 支援從 GitHub 倉庫載入外部模板。使用方式：
1. 在模板市場裡點擊「來自 GitHub」
2. 輸入倉庫位址（格式：`owner/repo`）
3. Studio 會讀取根目錄的 `ordo-template.json` 清單，展示可用的模板列表
4. 選擇一個，預覽後一鍵建立

**發布模板規範**

在倉庫裡放置以下內容即可：
- `ordo-template.json`：模板元資料（名稱、說明、標籤、預覽圖）
- `rules/`：規則檔案目錄
- `tests/`：測試案例目錄

## 開始使用

開啟 Studio，點擊「新建專案」，選擇「從模板建立」。有想貢獻的模板歡迎在 [GitHub](https://github.com/Ordo-Engine/Ordo) 提 PR。
